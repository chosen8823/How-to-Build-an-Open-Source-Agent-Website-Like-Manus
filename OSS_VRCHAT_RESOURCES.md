## 🎤 Speech-to-Text (Free, No Cloud Cost)

### 4. VRCTextboxSTT ⭐ BEST LOCAL STT

**Repository:** https://github.com/I5UCC/VRCTextboxSTT

**What it does:**
- FREE local speech-to-text using Whisper
- No cloud API needed (runs on your PC)
- Sends transcribed text to VRChat OSC
- OBS Browsersource support
- SteamVR overlay

**How to use:**
```bash
git clone https://github.com/I5UCC/VRCTextboxSTT.git
cd VRCTextboxSTT
pip install -r requirements.txt

# Run the app
python main.py
```

**Models (choose based on PC power):**
- `tiny` - Fast, least accurate
- `base` - **Recommended for most PCs**
- `small` - Good balance
- `medium` - Better accuracy
- `large` - Best accuracy (requires powerful PC)

**Why use it:**
- ✅ Completely free (no API costs)
- ✅ Runs locally (no internet needed)
- ✅ Fast (< 500ms latency with `base` model)
- ✅ Works with any VRChat avatar

**License:** Open source

## 💡 Tips for Using OSS Projects

### License Compliance

1. **Check Each License**
   - Read LICENSE file in each repository
   - Attribution may be required (CC-BY)
   - Some are public domain (CC0)
   - MIT/Apache are very permissive

2. **Avatar Licenses**
   - CC-BY 4.0 = Give credit to creator
   - CC0 = No attribution needed
   - Check model metadata

3. **Code Licenses**
   - MIT = Free to use, just include license
   - GPL = Share modifications
   - Apache = Similar to MIT

### Best Practices

1. **Fork, Don't Copy**
   - Fork repositories on GitHub
   - Keep connection to original
   - Easy to pull updates

2. **Give Credit**
   - Link to original projects
   - Credit creators in your docs
   - Share improvements back

3. **Stay Updated**
   - Watch repositories for updates
   - Check for security fixes
   - Pull new features
